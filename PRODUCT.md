# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Students keeping a private personal to-do list. The user confirmed assignment-only scope on 8 October 2026.

## Product Purpose

A two-person Database Lab 2 application demonstrating registration, login, and private task CRUD with plain MySQL queries.

## Operating Context

Local Flask application, laptop and mobile browser around 360 px wide; Python, MySQL, DBeaver, and VS Code.

## Capabilities and Constraints

Register, log in/out, add/edit/delete tasks, mark done/open. Each user sees only their own tasks. Duplicate titles within a user's list are prevented; separate users may reuse titles. Bcrypt, parameterized SQL, server-side sessions and CSRF protection remain. No additional product features or external services.

## Evidence on Hand

The assignment PDF, working repository, and two-member contribution history. Screenshots must show the real running app with disposable demonstration data.

## Product Principles

Keep task actions obvious. Preserve privacy at every database write. Explain validation errors and how to recover. Keep the assignment easy for both teammates to explain.
